# 台灣常識快問快答

使用 p5.js、ml5.js FaceMesh 與 webcam 製作的 10 題是非題小遊戲。

## 玩法

- 開啟後會先看到 landing page，按「開始遊戲」進入題目。
- 題目與作答提示固定在畫面上方，盡量不遮住臉部偵測區。
- 畫面會出現「請作答」。
- 嘴巴打開代表 YES。
- 嘴巴閉起代表 NO。
- 答對會播放 3 秒特效並進入下一題。
- 答錯會停在同一題，請再答一次。

## 執行方式

請用 localhost 開啟，webcam 權限比較穩定：

```powershell
python -m http.server 5500 --bind 127.0.0.1
```

然後在瀏覽器開啟：

```text
http://127.0.0.1:5500/
```

開啟網址後會直接進入遊戲 landing page，按「開始遊戲」即可作答。

目前程式已經使用 CDN 引用：

- p5.js 1.11.13
- ml5.js 1.x
